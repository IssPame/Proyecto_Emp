# Proyecto_Emp
PMN del Proyecto Análisis de Sentimientos en Redes Sociales para Empresas

El analizador de sentimientos en redes sociales es una página web dirigida a las empresas.
La finalidad de esta página es, como su nombre indica, ayudar a las empresas a medir la aceptabilidad de sus publicaciones en las redes sociales.

La página ofrece distintos tipos de gráficos, para que el usuario busque el más acorde a sus necesidades.
También cuenta con una guía de usuario básica para ayudar al usuario a dar sus primeros pasos.
