# Proyecto_Emp
PMN del Proyecto Análisis de Sentimientos en Redes Sociales para Empresas

El analizador de sentimientos en redes sociales es una página web dirigida a las empresas.
La finalidad de esta página es, como su nombre indica, ayudar a las empresas a medir la aceptabilidad de sus publicaciones en las redes sociales.

La página ofrece distintos tipos de gráficos, para que el usuario busque el más acorde a sus necesidades.
También cuenta con una guía de usuario básica para ayudar al usuario a dar sus primeros pasos.

# Navbar
Ofrece los botones principales, tipos de graficos, medir opiniones, guia de usuarios y cerrar sesión

# Footer
Redirige a las redes sociales "de MediGraph"

# Carrusel
Como si nombre indica, un carrusel de los distintos tipos de graficos

# Home
Presenta el nombre de la página, un subtítulo llamativo, y el carrusel mencionado anteriormente

# Tipo de gráficos
Como su nombre indica, muestra los gráficos disponibles en la aplicación, al seleccionar un grafico manda una alerta

# Medir Opiniones
Ayuda al usuario a medir la opinión de los demás usuarios en redes sociales

# Guía de Usuario
Guia básica de como usar la página web
